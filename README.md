# M-Motors -   BLOC 3

Application web de gestion de véhicules d'occasion et location longue durée (LLD).

## Stack
- Backend : FastAPI + PostgreSQL
- Frontend : React
- Tests : Pytest
- Déploiement : Docker + Railway

## Structure
- `backend/` - API FastAPI
- `frontend/` - Interface React
- `docs/` - Documentation technique
